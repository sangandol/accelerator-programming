# 加速器编程：TPU、GPU、CUDA 与 JAX

本书写给有数学训练、懂一点计算机体系结构、想尽快学会整套加速器编程体系的读者。全书自底向上：从逻辑门和加法器出发，经过乘法器、存储、流水线、矩阵单元，搭起一颗芯片和一组芯片；再讲在这样的机器上组织计算的共同结构；最后分成 TPU 和 GPU 两条路线，讲各自的结构、编程模型和典型 kernel。

每一层都写成一个模型：有什么状态、能做什么操作、各要付出多少代价。每章末尾的"接口小结"列出上层会用到的结论，初读时可以只读接口、跳过实现，像引用定理一样往上走。

先读[前言](00-preface.md)，其中给出阅读路线、记号和习题体例。

## 阅读路线

- **TPU 路线**：第一部分 → 第二部分 → 第三部分 → 第四部分。
- **GPU 路线**：第一部分 → 第二部分 → 第五部分。第三部分（JAX）选读，只在第 24 章讲 Pallas GPU 的一节用到。
- 第四部分和第五部分互不依赖。其中偶尔出现的"注（对照）"可以跳过。

### 第一部分　硬件：从逻辑门到多芯片

### 第二部分　计算的共同结构

第一部分给出了机器能做的操作与代价；本部分说明怎样把数学计算放到这种机器上：下标落在哪里，数据何时可以读或覆盖，局部状态怎样合并，一个模型究竟有多少算术、存储与通信。读完能先写出布局、依赖、不变量和性能预算，再审查 AI 生成的程序。布局、输入槽、在线归约、KV 预算和流水线空泡都配有可改参数的互动。

8. [布局](08-layouts.md)：布局作为下标到物理位置的函数；步长与转置视图；分块布局；寄存器布局与窄类型打包；存储体冲突与 XOR 交错；$\mathbb{F}_2$ 线性布局；访存合并与对齐；布局转换的置换与代价。
9. [异步程序与软件流水线](09-async.md)：事件与先行发生；读前等待与覆盖前等待；计数信号量及完成身份；多缓冲；延迟、吞吐与所需输入槽；序幕、稳态和尾声；死锁与进展；释放、获取和作用域。
10. [归约、扫描与在线算法](10-reductions.md)：映射—归约—收尾；可合并状态与结合律；在线 softmax 的最大值、分母和重缩放；注意力的未归一化加权和；Welford/Chan 方差；top-k 的状态合并；仿射递推与前缀扫描；浮点归约次序与可复现性。
11. [Transformer 的算术](11-transformer.md)：张量形状与参数量；投影、注意力、MLP 的 FLOPs 和字节；前向、反向与训练状态；提示处理与逐步解码；KV cache、MQA/GQA 的容量与带宽；混合专家的实际活跃工作量；量化格式、尺度与端到端估算。
12. [并行策略](12-parallelism.md)：逻辑 mesh 与复制；分片矩阵乘法的输出块和 K 部分和；数据并行与全分片数据并行；张量并行；序列/上下文并行；流水线并行的微批量与空泡；专家并行的分发与回收；通信重叠、训练一步和解码一步的资源账。

### 第三部分　JAX

把第二部分的计算规格写成有类型的程序。先理解追踪与函数变换，再给数组指定分片；全局数学形状、每设备局部形状、复制与集合通信分别核对。读完能解释编译缓存、自动微分与显式分布式程序的行为。缓存键和分片容量的互动帮助区分“值变了”“类型变了”和“存储归属变了”。

13. [JAX 的计算模型](13-jax.md)：数组、pytree 与纯函数；抽象值、追踪与 jaxpr；jit、降低与编译缓存；正向/反向自动微分；残差、重计算与自定义反向；vmap 的批处理规则；设备控制流与 scan；显式随机 key、全局计数器和精度规格。

### 第四部分　TPU

17. [TPU kernel：矩阵乘法与访存受限算子](17-tpu-matmul.md)：块强度、VMEM 缓冲预算与 DMA/MXU 重叠；结尾融合的线性与非线性边界；量化与块尺度；归一化、方差和 softmax 的归约轴；分组 GEMM 的专家区间、动态下标与嵌套流水线；DMA 发起次序、内部 dot 块、权重准备摊销与写回尾巴；性能和正确性审查。
